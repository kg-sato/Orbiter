# Orbiter 0.5.1 local verification

## Scope

Approved living-pond artwork promoted into `src/mascot`, `src/pond` and the shared transition controller. Root `Application.html` remains canonical; generated browser, phone and native copies are regenerated by the existing build pipeline. Existing `com.kgsato.orbit` identity, database, updater key, ownership and timer authority are preserved.

## Completed checks

**Local follow-up:** after the initial installer, a reported desktop layering issue was repaired by moving the reflected-water canvas into the shared top-layer overlay. Incoming content still shares the wave boundary; only decorative pixels overlay it and all pointer input passes through. Application copies and the local installer were rebuilt. The checks below describe the earlier build; this follow-up has not received another automated or hands-on visual test. The artifact size/hash below is superseded by the rebuilt installer and its adjacent `SHA256SUMS.txt`.

**Second follow-up, inspected in the demo and real HTML:** the layering-only repair was insufficient. Real planner layout wrappers use `display: contents`, so applying a clip to them did not reveal their painted descendants. The controller now descends through boxless wrappers and clips real card surfaces. The demo imports this exact controller rather than maintaining an older implementation. Queued automatic scroll events cancel effects only when the destination actually moves. Intermediate/finished captures were inspected; motion recordings are in `build/verified-motion/{demo,application}.webm`. `test_lake.cjs` passed with a new real-panel regression assertion; `test_island.cjs` passed after the queued-scroll repair. These are browser/HTML checks, not a claim of an installed Windows visual check.

- Native Rust suite: 33 passed, including transactional rewards, growth attribution, timer recovery, recap persistence, cloud queue rollback and legacy backup compatibility.
- `test_cosmic.cjs`: passed GLB budgets, morph targets, loading failure, preview/Cancel/locked items, one WebGL context, scene preferences, phone widths and reduced motion.
- `test_lake.cjs`: passed navigation and popup input, closing, secondary tabs, interruption, all palette/material/accent combinations, phone widths, Escape, resizing, reduced motion, Low and graphics failure.
- `test_island.cjs`: passed compact sizes, rewards/reveals, equipment preview and cancellation, growth and shared transitions.
- `test_unified.cjs`: passed reciprocal cat switching, draft preservation, native timer integration, sizing and browser identity/layout checks. A decorative canvas/background grid conflict found during this check was repaired before final packaging.
- Final transition sample: mean 0.64 ms / maximum 1.30 ms CPU draw, approximately 8.82 MiB of explicitly allocated 2D canvas buffers. Browser/driver memory is additional.
