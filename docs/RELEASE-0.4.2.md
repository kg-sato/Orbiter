# Orbiter 0.4.2

- Check for updates from planner preferences or buddy settings, with optional startup checks.
- Preview release notes and download verified updates directly in Orbiter.
- Installation pauses and saves the timer and creates a workspace recovery backup.
- Delete Atlas courses while retaining linked tasks, calendar events and focus history.
- Selected Atlas course cats remain animated in 3D.

This version needs one manual installation to enable future in-app updates. Windows installers are not Authenticode signed. Updater signatures verify that update packages use Orbiter's release key.
