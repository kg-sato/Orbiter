# Evolving orbit

Five visual stages: Seed, Awakening, Flow, Radiance, Cosmos. Derived from saved data; no database migration, artificial rewards or external services. Global score = 2 per course + 0.5 per unique event + 1 per assignment + 4 per completed assignment + 0.75 per completed step + completed focus minutes / 90. Thresholds 0, 8, 24, 55, 110. Unique events use course/title/day/start/end/kind, so repeated template copies do not inflate growth. Per-course versions use that course's events, assignments, steps and task-linked focus sessions, with thresholds 0, 3, 9, 20, 40. Unlinked focus sessions count globally.

The same stage controls both 3D sculptures: start with a dark sphere and one accretion ribbon, then reveal up to four fine filaments and twelve sparse stars. All meshes are uploaded once; draw ranges expose only unlocked detail. Course SVGs develop their own detail, while background dust, logo glow and timer halo subtly reflect global growth. The Atlas stage label has a tooltip showing its inputs. Deleting/importing/changing the saved workspace can simplify the visual again; this is not a permanent lifetime level. Native data exports and sync remain unchanged. Reduced motion gets a static evolved pose.

Popup fix: shared three-column header grid reserves independent title, morph emblem and close-control tracks. At very narrow widths the decorative emblem hides so close controls and text retain space. Borders are 2px and popup widths/padding increased. Workspace previously used an unstyled close control and nested padding, causing the overlap.
