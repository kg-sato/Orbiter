# Companion improvement plan

## Current direction

An original illustrated cream cat, with dusty rose outlines, blue scarf, lilac stars and sage sparks. It complements Scheduler's glass palette while having its own colors. Orbit rings are replaced by the scarf, tail, paws and small decorations. Pointer response remains layered and dimensional; typing inside the app alternates paw lifts and bounces the scarf. No system-wide key capture is used.

## 1. Make everyday use obvious

- Introduce a first-run welcome with three choices: start a focus session, import Scheduler, or create a task.
- Make the collapsed buddy show one clear action and the next intention; simplify the remaining controls.
- Add an obvious tray status, pause indicator and return-to-buddy action.
- Keep Desktop / Start shortcuts and Open Orbit.cmd as the everyday launch paths. Reserve the installer for setup.

## 2. Give the cat a coherent animation language

- Define idle, curious, typing, focusing, paused, celebrating and resting poses with consistent timings.
- Improve the independent tail, ear and paw motion; avoid stacking reactions when typing quickly.
- Keep typing reactions local to the app. Decide explicitly if desktop-wide reactions are ever desired before introducing any OS keyboard hook.
- Let the user choose calm, expressive or still behavior. Test legibility and character cropping at the collapsed window size.
- Use original illustrated assets consistently. Consider a true mesh model only after comparing its visual benefit with memory, package and battery costs; current depth is SVG/CSS perspective.

## 3. Make study tracking usable without the full website

- Show one next exam, today's practice target and remaining preparation time in the compact panel.
- Separate assignments, exams and recurring practice with concise creation flows.
- Give early finish, break and resume actions clear feedback, preserving actual focused minutes.
- Add preparation suggestions with an explicit preview before saving sessions.

## 4. Integrate the shared workspace cleanly

- Add visible paired/disconnected status and a one-click Open Scheduler action.
- Explain independent browser URLs during import rather than surprising users with separate data.
- Improve conflict review to compare the newer saved item against the user's draft.
- Add a guided export/restore flow covering study data versus the complete native profile.

## 5. Rework rewards around the cat

- Rename ring cosmetics as compatible accessories: scarf patterns, charms, particles and cat appearances.
- Preserve existing inventory IDs and earned rewards through a migration; do not silently reset collections.
- Show equipped items on the new character, with readable previews and a short reward reveal.
- Keep odds, free rewards and duplicate protection visible.

## 6. Stabilize and measure before expanding scope

- Review real lock/suspend/reboot recovery, notification delivery and single-instance behavior.
- Inspect multiple monitors, scaling and keyboard accessibility on the installed app.
- Repeat resource measurements with the new artwork and typing reactions; resolve the visible-memory target before declaring release acceptance complete.
- Review installer upgrade/uninstall and persistent reminder behavior.

Recommended next implementation: **first-run onboarding and a simpler compact focus control**, followed by the cat animation states and accessory migration. Changes remain local and uncommitted.

## Orbiter 0.1.1 — first Study Buddy refinement

- Project and app display name: Orbiter. The existing database identifier and browser storage keys remain stable for continuity.
- Removed the extra bottom-right mascot. Main page centerpieces retain the character.
- Open eyes give the short blink a visible change; idle breathing and tail sway complement pointer and typing reactions. Motion preferences continue to apply.
- Expanded Study Buddy has a smaller illustrated identity header and more compact timer spacing. The cat remains visible when controls are expanded.
- Next: first-run import guidance, compact next-exam/practice summary, and cosmetic accessory previews. Physical lock/sleep and multi-monitor checks remain pending.
