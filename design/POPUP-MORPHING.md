# Sculpted popup collection

Refreshed Event, Capture, Search and Workspace preferences with a shared glass header, original liquid sigil and clearer groups. The event title and Capture idea are primary writing surfaces. Optional event notes/repeat controls live in an expandable detail area, opened automatically for existing notes and rhythm editing. Preferences are organized into pace, appearance and study-hour sections.

Morphing is finite and interaction-driven: the header sigil changes shape when focus enters a new field/group; focused inputs reshape their corners and glass fill; buttons compress into a different radius. Existing Wave Wipe and native dialog focus/Escape semantics are retained. Smaller phone headers and panels adapt to available height.

Reduced motion suppresses the focus morphs and CSS transitions. Solid/transparency/contrast choices retain readable surfaces. Input IDs, validators, save handlers and underlying data formats are preserved.
